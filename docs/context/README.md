# FitCheck Context Folder

This folder is a compact, project-local, human-reviewed memory for reusable project decisions and lessons.

- `decisions.md`: accepted decisions and their source/date/status.
- `lessons.md`: evidence-backed lessons from implementation and verification.
- `worklog.md`: milestone summaries and next actions.

Rules:

- Append factual summaries, not conversation transcripts.
- Do not store secrets, user identities, uploaded product images, camera frames, screenshots containing people, or personal data.
- Keep uncertain/unverified claims labeled as such.
- Context changes go through the same PR/MR review as code. `AGENTS.md`, hooks, CI, and security controls are never self-edited by an agent without human review.
- Compact old worklog entries when needed; preserve active decisions and risks.
